# KoreanBible Reader v0.3.10

## 장 이동 버그 수정

이제 다음 조작은 항상 선택한 장의 **첫 번째 읽을 수 있는 절(일반적으로 1절)**로 이동합니다.

- 성경책 선택 → 1장
- 장 드롭다운 선택
- 왼쪽 성경 목록 → 장 번호 선택
- 태블릿 2분할 → 장 번호 선택
- 통독 계획에서 장 선택
- 즐겨찾기 장 이동
- 이전 장 / 다음 장
- 책 즐겨찾기/최근 책 → 1장

## 읽던 위치 복원은 별도 동작

다음 버튼만 이전 스크롤 위치를 복원합니다.

- `계속 읽기`
- Drawer의 `이어 읽기`
- 현재 읽던 위치 바로가기

즉:

**직접 장 선택 = 1절**
**계속 읽기 = 마지막 읽던 위치**
**검색/보관함의 특정 절 = 정확한 해당 절**

로 동작을 분리했습니다.

## 추가 버그 수정

기존 Drawer에서 성경책 이름만 선택해도 `currentBook`이 미리 바뀌는 문제가 있었습니다.

그 상태에서 장을 선택하면 이전 페이지의 스크롤 위치가 새 책의 장 위치로 잘못 저장될 수 있었습니다.

v0.3.10에서는:
- `chapterPickerBook`을 별도 사용
- 실제 장을 누르기 전에는 currentBook을 변경하지 않음

으로 수정했습니다.
