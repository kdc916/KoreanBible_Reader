# KoreanBible Reader v0.3.4

## 가장 중요한 변경
이제 페이지를 열었을 때 `성경 복구 중...` 상태로 오래 기다리지 않습니다.

### GitHub Pages 권장 방식
GitHub Actions가 빌드 시 전체 31,102절을 `index.html`에 직접 넣습니다.

그 결과 배포된 페이지는:
- 성경 네트워크 다운로드 없음
- CORS 복구 없음
- JSONP 없음
- 66권 분할 복구 없음

상태로 시작할 수 있습니다.

## 일반 HTML Fast Boot
완전 내장 빌드가 아닌 경우에도:
- 이전 전체 캐시
- 현재 성경책 `data/*.json`
- 같은 저장소 전체 JSON

을 먼저 사용합니다.

현재 권만 확보되면 바로 읽기를 시작하고
전체 66권은 뒤에서 준비합니다.

## 느린 복구
CORS proxy / JSONP / 66권 분할 복구는 더 이상 자동 실행하지 않습니다.

`느린 호환 복구`를 사용자가 직접 눌렀을 때만 실행됩니다.
