# KoreanBible Reader v0.3.3

## 컬렉션
말씀 보관함에서 `컬렉션 관리`를 누릅니다.

예:
- 위로받는 말씀
- 암송
- 가족
- 기도

컬렉션을 만든 뒤 저장된 말씀 옆 선택 메뉴에서 배정할 수 있습니다.

## 검색 결과 빠른 기능
검색 결과에서 바로:
- ★ 책갈피
- ▰ 노랑 형광펜
- 본문 열기

를 사용할 수 있습니다.

## 책 / 장 즐겨찾기
본문 장 제목 옆:
- ☆ 책
- ☆ 장

버튼을 누릅니다.

즐겨찾기는 화면 상단에서 빠르게 이동할 수 있습니다.

## 키보드 단축키
PC/태블릿:
- Ctrl/⌘ K : 검색
- Alt ← / → : 이전/다음 장
- H : 오늘
- B : 보관함
- F : 집중 모드
- ? : 도움말

## Markdown / TXT 내보내기
말씀 보관함에서:
- Markdown 내보내기
- TXT 내보내기

를 사용할 수 있습니다.

메모, 태그, 컬렉션 정보도 함께 포함됩니다.

## 데이터
v0.3.3부터 Storage Schema 4를 사용합니다.
이전 v0.3.x 데이터는 자동 마이그레이션됩니다.
